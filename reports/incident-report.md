# SOC Network Security Monitoring Lab - Incident Report



## 1. Executive Summary



This project demonstrates a hands-on Security Operations Center (SOC) network monitoring workflow using Kali Linux, Snort, Suricata, Zeek, Filebeat, Elasticsearch, and Kibana.



Network traffic was generated in a controlled lab environment and monitored using multiple network security tools. The collected telemetry was forwarded to Elasticsearch and visualized through a Kibana dashboard.



## 2. Lab Environment



- Operating System: Kali Linux

- Network Interface: eth0

- Lab IP: 192.168.91.128

- Elasticsearch: 9.5.2

- Kibana: 9.5.2

- Filebeat: 9.5.2

- Suricata: 8.0.6

- Zeek: Source-built installation

- Snort: Snort 3

## 4. Detection and Monitoring



### Zeek



Zeek was configured to monitor network traffic on the eth0 interface.



The following telemetry was collected:



- Network connections

- DNS activity

- Source IP information

- DNS queries

- Connection metadata



Example network activity was generated using:



- ping

- DNS queries using dig



### Suricata



Suricata was configured to generate EVE JSON telemetry.



A custom lab rule was created to safely generate an ICMP detection:



- Rule ID: 1000001

- Rule name: SOC LAB - ICMP Test Alert

- Protocol: ICMP



The alert was successfully generated by sending ICMP traffic from the Kali lab system.



### Snort



Snort was configured with a custom lab detection rule.



The test alert was successfully generated and recorded in the Snort alert JSON log.



Rule ID:



1000001



The alert was based on controlled ICMP traffic generated inside the lab.



## 5. Log Collection



Filebeat was used to collect security telemetry and forward it to Elasticsearch.



The Elasticsearch data included the following datasets:



- suricata.eve

- zeek.connection

- zeek.dns

- snort.alert



## 6. Elasticsearch Results



The lab successfully stored security monitoring events in Elasticsearch.



The collected events included:



- Suricata network telemetry

- Zeek connection telemetry

- Zeek DNS telemetry

- Snort alert telemetry



These events were searchable through Elasticsearch and available for visualization in Kibana.



## 7. Kibana Dashboard



A SOC Network Security Monitoring Dashboard was created in Kibana.



The dashboard includes visualizations for:



- Zeek Network Connections Over Time

- Zeek DNS Activity Over Time

- Top DNS Queries

- Top Source IPs

- Security Events by Dataset

- Suricata Events Over Time

- DNS Response Codes

- Suricata Alerts Count



The dashboard provides a centralized view of network security telemetry collected from the lab environment.



## 8. Investigation Summary



The lab demonstrated the workflow used by a SOC analyst to:



1. Generate controlled network traffic.

2. Capture network activity.

3. Detect traffic using IDS tools.

4. Collect security logs.

5. Forward logs using Filebeat.

6. Store events in Elasticsearch.

7. Search and analyze events.

8. Visualize security telemetry in Kibana.

9. Validate detections using controlled test traffic.



## 9. Conclusion



This project demonstrates a complete network security monitoring pipeline using multiple open-source security tools.



The lab successfully demonstrated network visibility, IDS alert generation, centralized log collection, Elasticsearch-based event storage, and Kibana-based security monitoring.



The environment can be extended with additional detection rules, threat-hunting queries, automated response workflows, and additional SOC dashboards.
